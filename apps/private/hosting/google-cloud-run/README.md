# Hosting Fast-Path: Google Cloud (Cloud Run & Cloud Run functions)

**Topology:** Managed Serverless Containers & Cloud FaaS on Google Cloud Platform (GCP)

Google Cloud offers two first-class serverless paths for running a single-tenant or multi-tenant
Storefront Private App:
1. **Google Cloud Run Services** (containerized Node/Python/Go/Java service scaled to zero or $N$
   instances, using the `Dockerfile` generated by `tot app scaffold`).
2. **Google Cloud Run functions** (`@google-cloud/functions-framework`, zero-Dockerfile function
   deployment).

Pair either with **Cloud Scheduler** (5-minute reconciliation trigger), **Google Cloud Secret
Manager** (`private_key_jwt` key storage), and **Firestore** (or **Cloud SQL**) for durable
`(tenantid, id)` CloudEvent deduplication and multi-tenant install state.

---

## 1. Option A — Google Cloud Run Service (`gcloud run deploy`)

Any app scaffolded with `tot app scaffold <name>` (or copied from [`../../recipes/`](../../recipes/))
can be deployed directly to Cloud Run from source or via its `Dockerfile`:

```bash
# 1. Store your private JWK in Google Cloud Secret Manager
gcloud secrets create tot-app-private-jwk --replication-policy="automatic"
gcloud secrets versions add tot-app-private-jwk --data-file=./private-key.jwk.json

# 2. Deploy the service to Cloud Run (HTTPS endpoint terminated by Google Front End)
gcloud run deploy tot-private-app-connector \
  --source . \
  --region us-central1 \
  --allow-unauthenticated \
  --set-secrets="TOT_PRIVATE_KEY_JWK=tot-app-private-jwk:latest" \
  --set-env-vars="WEBHOOK_PUBLIC_URL=https://tot-private-app-connector-<hash>-uc.a.run.app/webhooks/tot"
```

*(Note: `--allow-unauthenticated` at the Cloud Run ingress layer allows the Storefront webhook
gateway to reach `POST /webhooks/tot`; your handler authenticates every request cryptographically via
RFC 9421 `Signature` + `Content-Digest`.)*

### Configure 5-Minute Reconciliation with Cloud Scheduler

Create an OIDC-authenticated **Cloud Scheduler** job that triggers `POST /internal/reconcile` on
your Cloud Run service every 5 minutes:

```bash
gcloud scheduler jobs create http tot-connector-reconcile \
  --location=us-central1 \
  --schedule="*/5 * * * *" \
  --uri="https://tot-private-app-connector-<hash>-uc.a.run.app/internal/reconcile" \
  --http-method=POST \
  --oidc-service-account-email="tot-reconciler@<project-id>.iam.gserviceaccount.com"
```

## 2. Option B — Google Cloud Run functions (`@google-cloud/functions-framework`)

Google's Node.js Functions Framework parses JSON automatically into `req.body`, **but** preserves
the exact unparsed wire bytes in **`req.rawBody`** (`Buffer`). Always pass `req.rawBody` to your
RFC 9530 `Content-Digest` verifier:

```js
// index.mjs — Google Cloud Run function
import functions from "@google-cloud/functions-framework";
import { Firestore } from "@google-cloud/firestore";

const firestore = new Firestore();

functions.http("totWebhook", async (req, res) => {
  if (req.method === "GET" && req.path === "/.well-known/jwks.json") {
    return res.status(200).json({ keys: [JSON.parse(process.env.TOT_PUBLIC_KEY_JWK)] });
  }

  if (req.method !== "POST") {
    return res.status(405).send("Method Not Allowed");
  }

  // 1. Use req.rawBody (Buffer) provided by Functions Framework — NEVER JSON.stringify(req.body)!
  const rawBytes = req.rawBody;
  if (!rawBytes || !Buffer.isBuffer(rawBytes)) {
    return res.status(400).json({ error: "missing_raw_body" });
  }

  const event = req.body;
  const tenantId = event?.tenantid;
  const installId = event?.appinstallid;
  if (!tenantId || !installId || !event?.id) {
    return res.status(400).json({ error: "missing_cloudevent_context" });
  }

  // 2. Reconstruct public @target-uri behind Google Front End proxy
  const proto = req.get("x-forwarded-proto") || "https";
  const host = req.get("x-forwarded-host") || req.get("host");
  const targetUri = process.env.WEBHOOK_PUBLIC_URL || `${proto}://${host}${req.originalUrl}`;

  // 3. Verify RFC 9530 Content-Digest + RFC 9421 Signature
  const verified = await verifyTotWebhook({
    method: req.method,
    targetUri,
    headers: req.headers,
    rawBytes,
    tenantId,
  });
  if (!verified.ok) {
    return res.status(401).json({ error: verified.code });
  }

  // 4. Atomic deduplication in Firestore (create() fails with ALREADY_EXISTS on replay)
  const docRef = firestore.collection("totWebhookEvents").doc(`${tenantId}_${event.id}`);
  try {
    await docRef.create({
      tenantId,
      installId,
      eventId: event.id,
      receivedAt: new Date(),
      expiresAt: new Date(Date.now() + 7 * 86400 * 1000), // Configure Firestore TTL policy on expiresAt
    });
  } catch (err) {
    if (err.code === 6 /* ALREADY_EXISTS */) {
      return res.status(200).json({ ok: true, deduplicated: true });
    }
    throw err;
  }

  // 5. Route by (tenantId, installId)
  await handleStorefrontEvent(event, { tenantId, installId });
  return res.status(200).json({ ok: true });
});
```

## 3. Production Checklist on Google Cloud

- **Always verify against `req.rawBody`:** In Cloud Run functions or Express on Cloud Run, never
  recompute `Content-Digest` from `JSON.stringify(req.body)`.
- **CPU allocation during background work:** On Cloud Run, always complete your outbound `/api/apps/v1/*`
  calls (or enqueue to **Cloud Tasks** / **Pub/Sub**) *before* sending the HTTP response, unless CPU
  is set to `CPU is always allocated`.
- **Cloud Logging privacy:** Never write `shipTo` recipient fields from
  `GET /api/apps/v1/fulfillment/orders/{orderId}/recipient` to `console.log` or Structured Logging.
