# Recipes

End-to-end worked tasks. Each recipe is a directory with a `README.md` (the steps) and any files
you paste. Recipes assume you've started from a template and can run `tot dev` / `tot validate`.

- [`enable-pact-compliance/`](./enable-pact-compliance/) — turn on PACT Act + nicotine + excise for
  a vape/nicotine store.
- [`add-subscription-option/`](./add-subscription-option/) — offer a subscribe-and-save option the
  platform-safe way (the `purchase_options` data shape — not a custom widget).
